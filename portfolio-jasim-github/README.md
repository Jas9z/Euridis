# Jasim Bouchekoua, portfolio 2038

Portfolio de projection imaginé en 2026 : Jasim Bouchekoua, président de l'Olympique de Marseille en 2038.

Site statique en une page (HTML, CSS et JavaScript sans dépendance), publié avec GitHub Pages.

## Structure

```
index.html            la page
assets/img/           photos (générées par IA) et recadrages
assets/video/         vidéo du stade en MP4 et WebM
```

## Voir le site en local

Ouvrir `index.html` dans un navigateur.

## Mention

Les étapes à partir de 2028 sont fictives, les photos et la vidéo sont générées par IA. Site personnel sans lien avec l'Olympique de Marseille.
